# Gri Akademi — Sanat Kursu

Bakırköy Zeytinlik'te 2008'den beri faaliyet gösteren **Gri Akademi Sanat Kursu**'nun kurumsal web sitesi.

Güzel sanatlar fakültesi/lisesi hazırlık, portfolyo danışmanlığı, hobi resim, seramik, mozaik ve vitray atölyeleri.

## Teknik
- Saf **statik HTML + CSS + JS** (bağımlılıksız)
- Tasarım: "Gece ve Tebeşir" — koyu gece zemini + tebeşir + amber vurgu
- Tipografi: Fraunces (serif) + Inter
- Çok sayfalı: ana sayfa + 10 hizmet sayfası + çıkmış sorular arşivi
- Her hizmet sayfası aynı 14 bloklu şablon (SEO + FAQPage/Course schema + dönüşüm odaklı CTA)

## Yerel çalıştırma
```bash
node server.js       # http://localhost:7965
```
